# Girls Winter Boutique — Operations (Page 3 of 3)

## Who manages what

| Area | Managed in |
|------|------------|
| Products, prices, stock | Shopify Admin → Products |
| Orders and refunds | Shopify Admin → Orders |
| Page text and images (most) | Shopify Admin → Themes → Customize |
| Checkout and payments | Shopify Admin → Settings |
| Theme code changes | Developer with theme folder access |

## Live theme

The production theme is published on store **y9yn6k-me.myshopify.com**. Theme customisations are stored in Shopify; a copy of the theme files is kept in the project folder **girls winter** for version control and developer work.

## Publishing theme updates

Authorised developers deploy file changes using Shopify CLI, targeting the live theme ID **154447118405**. Content-only changes should be done in the theme customiser when possible to reduce risk.

## Handover notes

- Twenty products are set up with theme-hosted images.  
- Shipping and Returns are custom pages at `/pages/shipping` and `/pages/returns`.  
- Footer wardrobe links point to Shop page sections, not standalone collection pages.  

## Recommended review before campaigns

Confirm Shop links, sale countdown, announcement text, and product availability. Test Add to Cart and checkout on a real device.
